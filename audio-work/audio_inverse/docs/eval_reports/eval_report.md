## 读出来的结论

1. **召回解决**：0.965~1.000，连 dense（4 秒 8~12 事件、3~5 重叠加）都是 0.966 -> 起始脉冲目标生效
2. **精确率是瓶颈**：0.559~0.657。dense 层 14479 个事件检出 25020 个，过检 73%
3. **根因**：当时 `min_ev=1`，训练里每个窗口都至少有一个事件，模型从未见过空窗，没有"静音"概念
4. **识别**：easy 82.4% / mid 68.3% / hard 51.2% / dense 27.8%；dense 层即使对人也很勉强
5. **PCEN 消融决定性**：hard 层 top-1 51.2% -> 1.8%（无 PCEN）

## 之后的改动

- `--empty-frac 0.2`：20% 训练样本为完全空窗
- 评测阈值改为按**事件 F1** 选取（原先按帧 F1）
- 新增"纯背景虚警率"指标

400 步验证（`eval --n 120`）：事件 F1 easy 0.899 / mid 0.841 / hard 0.831 / dense 0.794，
纯背景虚警 0.07 次/秒 —— 精确率从 ~0.60 提升到 ~0.80。
